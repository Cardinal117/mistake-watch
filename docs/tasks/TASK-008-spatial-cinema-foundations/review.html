Spatial Cinema Foundations

A cleanly rewritten desktop-3D and Quest/WebXR presentation inside the existing Mistake Watch room—sharing the real playback, queue, permissions, identity, and uploaded-media security systems.

Current recommendation

Approve the direction packet, then approve one bounded task at a time. Wait for TASK-007 to establish stable module seams before locking exact implementation paths. Start with a repository/dependency spike and primitive scale proof, not the finished cinema.

The direction being locked

Spatial Cinema is not another room product. It is a local way to experience the same authoritative room alongside ordinary Watch participants.

01Existing roomParticipant is already joined and authorized.
02Local presentationStandard Watch, desktop 3D, or Quest WebXR.
03Shared authoritySame playback, queue, permissions, chat, and media session.
04Spatial presenceOnly poses, seats, and reactions are newly synchronized.

Swipe down to summon

Highest-risk mistakes the packet prevents

Duplicate authority

A second playback or queue system would eventually desynchronize from ordinary Watch clients.

Private media regression

A direct R2 URL given to Three.js could bypass the existing room-session authorization contract.

Pose-driven rendering collapse

Publishing at headset frame rate or storing transforms in ordinary React state would damage Quest performance.

Lost or inaccessible controls

A hand-only gesture or unrecoverable world-anchored menu could trap the user without an exit.

Premature environment polish

A finished Kenney room before blockout measurements would encode untested scale, reach, lighting, and draw-call choices.

Provider scope explosion

YouTube textures and screen sharing are technically different problems and must not control the first milestone.

Recommended task order

Each stage has a review checkpoint. Approval of this packet does not approve every stage.

0

Approve direction

Confirm the product boundary, headset baseline, entry placement, and first interaction assumptions.

1

Post-refactor integration spike

Map stable modules, verify package compatibility, and prove lazy spatial loading.

2

Asset audit and primitive scale

Measure exact GLBs, approve shortlist, and establish metres, eye height, seats, screen, anchors, and colliders.

3

Solo desktop/Quest proof

Enter and leave safely, render the primitive room, and establish performance instrumentation.

4

Multiplayer presence and seats

Add spatial sessions, current poses, interpolation, avatars, atomic seats, and cleanup.

5

Secure cinema media

Project one direct/authorized uploaded source using the existing room authority and URL resolution.

6

Guaranteed system menu

Add spatial controls, downward swipe, all fallbacks, placement recovery, and comfort/accessibility behavior.

7

Vertical-slice gate

Two-client and standard-Watch coexistence QA on real target hardware.

8

Golden Orbital Cinema

Author the approved Kenney room and compare it against the primitive performance baseline.
