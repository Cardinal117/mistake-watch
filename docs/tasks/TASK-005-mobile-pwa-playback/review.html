Spec Review · TASK-005

Mobile PWA playback should improve the phone experience without overpromising background YouTube.

This task creates the mobile app-like foundation: installability, Media Session controls, safer background/resume behavior, and mobile room polish. Background playback is treated as source and browser dependent.

Goal

Installable Mobile Experience

Make Mistake Watch feel more app-like on mobile through PWA shell, standalone viewport handling, and mobile-first room ergonomics.

Playback

Media Session Controls

Expose supported lock-screen/notification controls while preserving room permissions and local-only guest resume behavior.

Boundary

No False Background Claims

Direct/R2 media is the realistic path. YouTube iframe background playback remains limited by provider and browser behavior.

Implementation Order
  • Audit manifest and production installability.
  • Add safe static-shell service worker behavior only.
  • Add permission-aware Media Session API integration.
  • Polish mobile room controls and standalone safe areas.
  • QA background/resume behavior by device, browser, and source type.
Risks
  • iOS may suspend background JavaScript and WebSocket activity.
  • YouTube iframe playback may stop in background regardless of PWA install.
  • Service worker caching must not cache auth, rooms, APIs, or media uploads.
  • Lock-screen controls must not bypass host/member permissions.
