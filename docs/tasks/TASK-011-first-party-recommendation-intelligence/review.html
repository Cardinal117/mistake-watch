Mistake Watch Like Signal

Signed-in accounts

Like state persists across devices against an opaque media identity and remains private to the account.

Guests

Like state is limited to the current room/session and expires with the approved guest retention policy.

Ranking effect

Like is stronger than replay or completion but capped by diversity and repetition controls. Remove Like restores neutral.

UI contract

A compact Lucide Heart uses aria-pressed, Like/Remove Like labels, tooltip, stable sizing, focus, and failure rollback.

This is an app-native preference and never calls YouTube's Like API or exposes who liked an item. It enables explanations such as Because you liked Julien Journet without revealing another participant's private history.

Proposed Data Flow

1. Room action

Queue or playback intent enters the existing authority path.

2. Reducer

SpacetimeDB validates permission and mutates live state.

3. Outbox

The same reducer records one versioned, idempotent event.

4. Durable sink

A trusted bounded drain writes service-only Supabase rows.

5. Ranker

Pure scoring returns candidates, reasons, and exclusions.

Private media rule

Uploaded playback may inform room-session analysis, but it cannot expose an uploaded catalogue candidate to a guest or unauthorized account. Events use opaque IDs, never R2 destinations.

Identity correction

A queue row is not a playback occurrence. Session, occurrence, action actor, and original contributor require separate stable identities before replay history is trustworthy.

Existing data warning

Current Supabase queue and playback tables are not mirrored on every live reducer transition. They cannot be reused as complete behavioral history.

Service hardening

Provider caching needs TTL, capacity, and failure expiry. Room recommendation reads must support signed-in membership as well as verified room-scoped guests.
