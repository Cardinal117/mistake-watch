What changed

  • Canonical transition events now originate inside authorized reducers.
  • Playback occurrence IDs prevent stale advances and source failures from mutating newer replays.
  • Completion requires an ended state or at least 90% progress.
  • Guest Likes are private, revision-checked, idempotent, and neutral when removed.
  • Member IDs cannot be rebound to another SpacetimeDB identity.
  • Smart Shuffle shares one action ID across its move reducers, so one shuffle creates one operational event without suppressing a later shuffle.
  • Pending outbox rows are never pruned; overflow is counted and logged.
