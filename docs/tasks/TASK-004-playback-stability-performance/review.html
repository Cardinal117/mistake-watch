Mistake Watch / TASK-004

Playback Stability and Listen Performance

Spec packet for the next approved work: fix audio correctness first, then reduce hidden render cost across listen mode.

Priority Audio correctness

Atomic autoplay and follower sync stability come before visual optimization.

Second pass Visibility budget

Closed, collapsed, mobile-hidden, or offscreen content should not render heavy UI.

Approval mode Spec-first

Stateful realtime, mobile playback, and performance work need controlled implementation slices.

Current Diagnosis

  • Non-controller YouTube clients have a stricter correction path than normal listen sync.
  • Mobile iframe state changes can trigger repeated seek/play corrections.
  • Autoplay currently advances through separate queue and playback reducer calls.
  • Hidden drawers, sidebars, animations, metadata hooks, and long lists can still cost render time.

Recommended Order

  1. Atomic SpacetimeDB autoplay reducer.
  2. YouTube transition guard.
  3. Non-controller listen sync tolerance.
  4. Queue drawer lazy render and virtualization.
  5. Sidebar, mobile visual, metadata, and thumbnail performance pass.

Atomic Autoplay Flow

The reducer should turn autoplay into one coherent room-state transition.

1

Validate playback authority and autoplay enabled.

2

Select next playable item using queue mode.

3

Mark current as played and next as playing.

4

Update session source, position 0, status playing.

5

Emit one canonical state to all clients.

Implementation Slices

Task 1

Atomic Autoplay Reducer

Add the reducer, regenerate bindings, update `advanceToNextQueueItem`, and verify queue semantics.

Task 2

YouTube Transition Guard

Suppress old-source events during autoplay/manual handoff so the old song cannot spike.

Task 3

Non-Controller Listen Sync

Relax unauthorized YouTube micro-correction while preserving meaningful drift correction.

Task 4

Queue Drawer Lazy Render

Closed drawer renders only the handle/count; open drawer renders bounded or virtualized rows.

Task 5

Sidebar Visibility Budget

Collapsed member rail avoids mounting full permission cards and member management controls.

Task 6

Mobile and Motion Budget

Disable heavy waveforms and offscreen animations on mobile, hidden tabs, and reduced-motion contexts.

Task 7

Metadata and Thumbnail Reduction

Share metadata by video ID and defer hidden/offscreen thumbnail and metadata work.
