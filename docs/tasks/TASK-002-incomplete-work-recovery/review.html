Key Risks

Playback stability

Listen quality and preload work must not remount players or mutate SpacetimeDB playback state unexpectedly.

Provider truth

Recommendations and metadata must show unavailable states rather than fake personal, provider-trending, or listening-history data.

Ambient motion

Watch-room ambience must shift slowly, respect reduced-motion, and use YouTube thumbnail/provider fallback instead of iframe frame sampling.

Authority boundary

Host authority must come from verified membership, not browser-provided reducer payload fields or client UI state.

Queue interaction debt

Full queue access, duplicate behavior, previous/back history, and Add Media stacking need a dedicated stabilization pass before the cinematic watch queue/library drawer is redesigned.

Future systems

Cloudflare Stream/R2, social rooms, achievements, AI DJ, browser mode, and broad hardening may need deeper design review before implementation.
