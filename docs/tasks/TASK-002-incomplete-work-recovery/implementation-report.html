Implementation Summary

Room Session Authority

room_media_sessions stores active uploaded-media playback sessions per room, with starter identity, member context, expiry, and audit timestamps.

Start Gate

Session creation requires catalogue authorization, room playback authority, and a ready uploaded media asset.

Watch Gate

Current room participants can be authorized to watch an active uploaded-media session without gaining catalogue browse access.
