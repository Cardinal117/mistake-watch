Implementation Summary

  • Added a shared listen discovery model so tabs have explicit room-queue, room-history, provider, provider-limited, or unavailable source states.
  • Kept For you queue-based and filtered known-unavailable items from room picks.
  • Made Recommended use server-side YouTube search when available, otherwise fall back to honest room-history recommendations.
  • Replaced Trending with Most listened, derived from host/room listening history for now instead of global provider trends.
  • Kept From your playlist account-aware by using room playlist/history matches only and showing accounts-required copy when no room data exists.
  • Added permission-aware recommendation actions for load/play, add to queue, and play next.
  • Added a reserved future AI DJ/session-intelligence home that only summarizes current queue/history signals and remains advisory.
  • Kept provider API keys server-side through the new recommendations API route.
