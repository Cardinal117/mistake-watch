Implementation Summary

Opaque References

Uploaded catalogue cards and first-party queue matches now use mw-uploaded-asset or mw-uploaded-session references instead of R2 URLs.

Server Resolver

The playback endpoint validates room membership, active session, matching room, and ready asset state before signing R2 access.

Player Resolution

The direct media player resolves uploaded session refs at load time and fails closed on unresolved uploaded asset refs.
