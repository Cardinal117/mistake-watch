TASK-002.5D / Implementation Report

Queue Authority And Add Media UX Stabilization

This corrective pass makes the visible QUEUE permission match real reducer authority, records actual playback history order, turns Add Media into a URL-driven centered modal, finishes playlist review controls, adds playlist duplicate handling, and surfaces visible queue feedback.

Implemented

Queue Authority

SpacetimeDB keeps add/manage fields internally, while the current member UI maps the visible QUEUE permission to both queue add and queue management authority.

Typecheck, lint, targeted tests, Next build, Spacetime build, and codegen passed.

Manual QA Pending

Two-Client Review

Guest QUEUE authority, duplicate/import behavior, and responsive modal layout still need host plus guest browser confirmation after local publish.

What Changed

Authority And History

  • Added `can_manage_queue` to SpacetimeDB live permissions while keeping one visible QUEUE permission in the member UI.
  • Mapped the visible QUEUE permission to both queue add and queue management reducer payload fields.
  • Moved move, remove, clear, pin, and play-next reducers to queue-management authority.
  • Kept playback control separate so playback-granted users do not automatically get queue powers.
  • Added `played_sequence` to live queue rows so previous/back can follow actual played order.

Add Media UX

  • Replaced the embedded/anchored Add Media surfaces with centered portal modals above room panels and queue drawers.
  • Removed the manual Add single song / Review playlist mode cards; URL input now auto-loads single or playlist preview.
  • Added duplicate detection before single and playlist mutation, an explicit Add anyway path, an Add without duplicates path, and a local remember-my-choice preference.
  • Expanded playlist review with search, duplicate-aware sort, select visible, select all, clear selection, add all, add selected, duplicate badges, and duration filters.
  • Added local queue notifications for add, duplicate, playlist import, load, and warning outcomes.
