Implementation Summary

App-Owned Allowlist

uploaded_catalogue_authorizations stores active or revoked catalogue authorization records. The table is not directly readable or writable by browser roles.

Server Gate

The media catalogue API checks owner role or active allowlist status before returning uploaded assets and folders.

No-Permission UI

Denied users see no uploaded cards, folder controls, or search controls. The uploaded tab shows a direct no-permission state.
