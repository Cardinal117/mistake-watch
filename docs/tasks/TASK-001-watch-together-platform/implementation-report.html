Layout

Listen Branch

RoomExperience now renders ListenModeLayout whenever the live session mode is listen. Watch Mode stays on the existing navigation, stage, sidebar, and transport structure.

Music UI

Now Playing

The left side is now a persistent Now Playing panel with artwork, visualizer, progress, playback controls, local volume, metadata, and a visible YouTube source monitor for provider-compliant listen playback.

Queue

Bottom Tray

Listen Mode now mounts the queue as a bottom-docked tray instead of normal center-column content. It defaults collapsed with a visible handle/header and expands upward to show search, shuffle, smart shuffle, pinned-first, clear, row actions, and wide queue rows.

Polish

Smooth Toggle

The drawer content stays mounted during transitions, so the tray can animate open and closed. The toggle is a full integrated header with queue count, embedded handle, and a rotating chevron instead of a detached-looking control.

Live Room

Removal Guard

The client now subscribes to live room_kick state and uses that as the immediate removal signal. Missing participant rows wait longer before redirecting, which reduces false removal notices during reconnect timing.

Sidebar

Queue Removed

The Listen right sidebar no longer has a redundant Queue tab. Queue management belongs to the bottom drawer, while the right sidebar now focuses on Members and Room context with the small Coming Up preview.

Members

Authority Controls

Listen Mode now uses the shared MembersPanel in the right sidebar. Hosts can adjust queue, playback, and browser permissions, grant or revoke controller, kick active members, and remove idle members from the same authority surface as Watch Mode.

Navigation

Leave Room

Listen Mode now has a top-left Leave Room action in the left Now Playing panel, matching Watch Mode's explicit exit affordance and using the existing pending navigation overlay.

Room Tab

Save Room

The Listen Mode Room tab now includes the host-only Save/Saved control. It uses the same saved-room server action as Watch Mode so saved rooms keep their queue and avoid idle cleanup.

Discovery

Connected Tabs

The Listen discovery filters are now a connected segmented selector instead of separate floating buttons, matching the fixed control language used elsewhere in the room.

Now Playing

Artwork Backdrop

The Now Playing panel now uses the active thumbnail as a blurred, saturated backdrop when artwork exists. Awaiting-media keeps the amber fallback because there is no real source artwork yet.

Task 21

Source Monitor

The visible YouTube source player now lives inside the fixed Now Playing artwork square instead of appearing as a separate block after playback starts. The geometry is reserved before metadata arrives, preventing the production layout jump.

Task 21

Ambient Theme

Listen Mode now uses active artwork as a blurred ambient page layer and applies source-derived cyan, amber, and blue glow variables within the Obsidian Lounge palette. The visualizer stays integrated over the source monitor without intercepting player controls.

Task 21

Discovery Stability

Center Room Picks now excludes the currently playing item, so the active song thumbnail is not enlarged awkwardly in the discovery surface. Upcoming queue items still populate the picks area.

Future Accounts

Personal Greeting

The Listen Mode greeting remains generic for the guest-first build. When Supabase accounts and profiles are added, this should use the account holder's display name, with a guest fallback.
